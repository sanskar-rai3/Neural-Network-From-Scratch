A feed-\/forward neural network implemented entirely in C, without machine-\/learning frameworks.

The purpose of this project is to understand how neural networks work internally by implementing the underlying mathematics and components directly rather than hiding them behind high-\/level libraries.

The network currently supports matrix operations, EMNIST loading, dense layers, activation functions, loss functions, backpropagation, configurable multi-\/layer networks, SGD optimization, EMNIST training, inference, accuracy evaluation, and sample rendering.\hypertarget{index_autotoc_md0}{}\doxysection{\texorpdfstring{Overview}{Overview}}\label{index_autotoc_md0}

\hypertarget{index_autotoc_md1}{}\doxysection{\texorpdfstring{Matrix Library}{Matrix Library}}\label{index_autotoc_md1}
The neural network is built on top of a custom matrix implementation.

Matrices use row-\/major storage.

For a matrix with rows and cols, the element at {\ttfamily (row, col)} is stored at:


\begin{DoxyCode}{0}
\DoxyCodeLine{mat-\/>data[row\ *\ mat-\/>cols\ +\ col]}

\end{DoxyCode}


The matrix library provides operations including:


\begin{DoxyItemize}
\item Matrix creation and destruction
\item Element access
\item Matrix copying
\item Matrix addition and subtraction
\item In-\/place arithmetic
\item Scalar multiplication
\item Hadamard product
\item Matrix multiplication
\item Transposition
\item Element-\/wise operations
\item Random initialization
\item Matrix filling
\end{DoxyItemize}\hypertarget{index_autotoc_md2}{}\doxysubsection{\texorpdfstring{Matrix Multiplication}{Matrix Multiplication}}\label{index_autotoc_md2}
For two matrices:


\begin{DoxyCode}{0}
\DoxyCodeLine{A\ =\ m\ x\ n}
\DoxyCodeLine{B\ =\ n\ x\ p}

\end{DoxyCode}


the result is:


\begin{DoxyCode}{0}
\DoxyCodeLine{C\ =\ m\ x\ p}

\end{DoxyCode}


Each element is calculated as:


\begin{DoxyCode}{0}
\DoxyCodeLine{C[i][j]\ =\ sum(A[i][k]\ *\ B[k][j])}

\end{DoxyCode}


Matrix multiplication is the primary operation used by dense layers.\hypertarget{index_autotoc_md3}{}\doxysection{\texorpdfstring{Dense Layers}{Dense Layers}}\label{index_autotoc_md3}
A dense layer performs an affine transformation:


\begin{DoxyCode}{0}
\DoxyCodeLine{Z\ =\ XW\ +\ b}

\end{DoxyCode}


where:


\begin{DoxyItemize}
\item {\ttfamily X} = input
\item {\ttfamily W} = weights
\item {\ttfamily b} = bias
\item {\ttfamily Z} = output before activation
\end{DoxyItemize}

For example:


\begin{DoxyTable}{2}{}{}{1}
\SetCell{c,bg=\tableheadbgcolor,font=\bfseries}&\SetCell{c,bg=\tableheadbgcolor,font=\bfseries}Shape  \\
Input  &64 x 784  \\
Weights  &784 x 128  \\
Bias  &1 x 128  \\
Output  &64 x 128  \\
\end{DoxyTable}


The same operation therefore processes an entire batch of samples at once.

Weights and biases are initialized when the layer is created.

During training, the layer also stores the information required for backpropagation.\hypertarget{index_autotoc_md4}{}\doxysection{\texorpdfstring{Activation Functions}{Activation Functions}}\label{index_autotoc_md4}
The network supports several activation functions:


\begin{DoxyItemize}
\item Re\+LU
\item Leaky Re\+LU
\item Tanh
\item Sigmoid
\item Softmax
\item Linear / None
\end{DoxyItemize}

Activations are applied to the output of dense layers.\hypertarget{index_autotoc_md5}{}\doxysubsection{\texorpdfstring{Re\+LU}{Re\+LU}}\label{index_autotoc_md5}

\begin{DoxyCode}{0}
\DoxyCodeLine{f(x)\ =\ max(0,\ x)}

\end{DoxyCode}


It is primarily used in hidden layers.\hypertarget{index_autotoc_md6}{}\doxysubsection{\texorpdfstring{Leaky Re\+LU}{Leaky Re\+LU}}\label{index_autotoc_md6}

\end{DoxyCode}

\hypertarget{index_autotoc_md9}{}\doxysubsection{\texorpdfstring{Softmax}{Softmax}}\label{index_autotoc_md9}
Softmax converts a vector of logits into a probability distribution.

For a vector {\ttfamily z}:


\begin{DoxyCode}{0}
\DoxyCodeLine{softmax(z\_i)\ =\ exp(z\_i)\ /\ sum(exp(z\_j))}

\end{DoxyCode}


The implementation subtracts the maximum logit before exponentiation:


\begin{DoxyCode}{0}
\DoxyCodeLine{exp(z\_i\ -\/\ max(z))}

\end{DoxyCode}


This improves numerical stability and prevents unnecessarily large exponentials.

For the EMNIST output layer, softmax produces ten probabilities corresponding to the ten digit classes.\hypertarget{index_autotoc_md10}{}\doxysection{\texorpdfstring{Layers and Network}{Layers and Network}}\label{index_autotoc_md10}

The project implements Mean Squared Error and Cross-\/\+Entropy.\hypertarget{index_autotoc_md13}{}\doxysubsection{\texorpdfstring{Mean Squared Error}{Mean Squared Error}}\label{index_autotoc_md13}
MSE is defined as:


\begin{DoxyCode}{0}
\DoxyCodeLine{L\ =\ (1\ /\ n)\ *\ sum((prediction\_i\ -\/\ target\_i)\string^2)}

\end{DoxyCode}


Its derivative with respect to the prediction is:


\begin{DoxyCode}{0}
\DoxyCodeLine{dL/dA\ =\ 2(A\ -\/\ Y)\ /\ n}

\end{DoxyCode}


MSE is useful for testing and understanding gradients, but it is not the preferred loss function for multi-\/class classification.\hypertarget{index_autotoc_md14}{}\doxysubsection{\texorpdfstring{Cross-\/\+Entropy}{Cross-\/\+Entropy}}\label{index_autotoc_md14}
For a prediction vector {\ttfamily P} and one-\/hot target {\ttfamily Y}:


\begin{DoxyCode}{0}
\DoxyCodeLine{L\ =\ -\/sum(Y\_i\ *\ log(P\_i))}

\end{DoxyCode}


For a one-\/hot encoded target, only the probability assigned to the correct class contributes to the loss.

For example:


\begin{DoxyCode}{0}
\DoxyCodeLine{Prediction:}
\DoxyCodeLine{\ \ \ \ [0.01,\ 0.02,\ 0.90,\ 0.01,\ ...]}
\DoxyCodeLine{}
\DoxyCodeLine{Target:}
\DoxyCodeLine{\ \ \ \ [0,\ 0,\ 1,\ 0,\ ...]}

\end{DoxyCode}


The loss is approximately:


\begin{DoxyCode}{0}
\DoxyCodeLine{-\/log(0.90)}

\end{DoxyCode}


The implementation clamps probabilities before taking the logarithm to avoid {\ttfamily log(0)}.\hypertarget{index_autotoc_md15}{}\doxysubsection{\texorpdfstring{Softmax + Cross-\/\+Entropy}{Softmax + Cross-\/\+Entropy}}\label{index_autotoc_md15}
The network has a combined backward path for softmax followed by cross-\/entropy.

For:


\begin{DoxyCode}{0}
\DoxyCodeLine{A\ =\ softmax(Z)}

\end{DoxyCode}


and cross-\/entropy loss, the derivative simplifies to:


\begin{DoxyCode}{0}
\DoxyCodeLine{dZ\ =\ A\ -\/\ Y}

\end{DoxyCode}


When training with a batch, the gradient is averaged:


\begin{DoxyCode}{0}
\DoxyCodeLine{dZ\ =\ (A\ -\/\ Y)\ /\ batch\_size}

\end{DoxyCode}


This avoids explicitly constructing the full softmax Jacobian and is both simpler and numerically appropriate for classification.\hypertarget{index_autotoc_md16}{}\doxysection{\texorpdfstring{Backpropagation}{Backpropagation}}\label{index_autotoc_md16}
Backpropagation calculates how much each parameter contributed to the loss.

The network traverses its layers in reverse order.

\begin{DoxyCode}{0}

Activation functions then transform that gradient according to their derivatives.\hypertarget{index_autotoc_md17}{}\doxysubsection{\texorpdfstring{Activation Backward Pass}{Activation Backward Pass}}\label{index_autotoc_md17}

\end{DoxyCode}

\begin{DoxyCode}{0}
\DoxyCodeLine{s\ =\ sigmoid(Z)}
\DoxyCodeLine{}
\DoxyCodeLine{dZ\ =\ dA\ *\ s\ *\ (1\ -\/\ s)}

\end{DoxyCode}

\begin{DoxyCode}{0}
\DoxyCodeLine{t\ =\ tanh(Z)}
\DoxyCodeLine{}
\DoxyCodeLine{dZ\ =\ dA\ *\ (1\ -\/\ t\string^2)}

\end{DoxyCode}


For the Softmax + Cross-\/\+Entropy combination:


\begin{DoxyCode}{0}
\DoxyCodeLine{dZ\ =\ dA}

\end{DoxyCode}


where {\ttfamily dA} has already been calculated as:


\begin{DoxyCode}{0}
\DoxyCodeLine{prediction\ -\/\ target}

\end{DoxyCode}


This is why the final activation can use a specialized backward path for cross-\/entropy.\hypertarget{index_autotoc_md18}{}\doxysection{\texorpdfstring{Optimization}{Optimization}}\label{index_autotoc_md18}

\begin{DoxyCode}{0}

\hypertarget{index_autotoc_md29}{}\doxysection{\texorpdfstring{Design Philosophy}{Design Philosophy}}\label{index_autotoc_md29}
This project intentionally avoids machine-\/learning frameworks.

The goal is not to reproduce the performance or feature set of libraries such as Py\+Torch or Tensor\+Flow.

The goal is to understand what those libraries are doing underneath.

The important operations are implemented directly:


\begin{DoxyCode}{0}
