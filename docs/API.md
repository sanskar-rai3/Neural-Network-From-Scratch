# API Documentation

The API reference is generated automatically using **Doxygen**.

## Generate the API Documentation

Make sure Doxygen is installed, then run:

```bash
doxygen Doxyfile
```

The generated documentation will be placed in the pages/ directory configured by `Doxyfile`.

For this project, the generated API documentation is the authoritative reference for the public API.

## Public API

The public API is provided through the headers in `include/`.

For detailed documentation of:

* Functions
* Structures
* Enumerations
* Parameters
* Return values
* Macros
* Types

generate the Doxygen documentation using the project's `Doxyfile`.

## Quick Start

From the repository root:

```bash
doxygen Doxyfile
```

Then open the generated documentation in your configured output directory.
