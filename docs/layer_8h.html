void layer_backward ( Matrix * d_input,
Layer * layer,
const Matrix * d_output )

Performs a backward pass through the layer, propagating the gradient through the activation function and underlying dense layer.

Parameters
d_inputDestination matrix for the gradient with respect to the layer input (dL/dInput). Must be pre-allocated with shape (batch_size x input_size).
d_weightsDestination matrix for the gradient with respect to the layer weights (dL/dW). Must be pre-allocated with the same shape as the layer's weights.
d_biasDestination matrix for the gradient with respect to the layer bias (dL/db). Must be pre-allocated with the same shape as the layer's bias.
layerPointer to the initialized Layer.
d_outputGradient with respect to the layer output (dL/dA). Must have the same shape as the layer's cached Z.
